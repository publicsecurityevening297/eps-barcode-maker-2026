## Overview

EPS Barcode Generator is a browser utility that converts EAN-13 values into editable EPS vector artwork. It handles both one-at-a-time generation and larger batches supplied through Excel or CSV files.

Built as a standalone web application, it fits production workflows where scalable PostScript files are needed for projects such as Adobe Illustrator work. The interface provides a live output preview, progress and status details, plus options to save files separately or bundle a batch into a ZIP archive.

1. Start the web application in a browser.

## Frequently Asked Questions

### Is single-barcode generation supported?

Yes. You can generate one EAN-13 barcode at a time or process several values in a batch.

### What files can I import?

Bulk processing accepts Excel and CSV files.

### Which files are generated?

The application creates EPS vector files. A group of generated files can also be downloaded as a ZIP archive.

### Does it work without an internet connection?

Yes. EPS Barcode Generator is intended to operate as a standalone, offline-capable web app. Obtain the application first, then open it locally in a compatible browser.

### Do I need a configuration file?

No. The documented workflow is configured through the browser interface and does not require an additional configuration file.

### What can I do if an upload fails?

Verify that the source is an Excel or CSV file, then retry using either drag-and-drop or the file picker. If the problem continues, try processing a smaller file.
