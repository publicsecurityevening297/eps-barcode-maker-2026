## 🎨 Why Use Vector Output?
The application saves your barcodes in the EPS file format. This format is the industry standard for professional printing. You can scale these barcodes to any size without losing image quality or clarity. This prevents errors when scanners read your product labels.

## 💡 Frequently Asked Questions

**Does the software track my data?**
No. This tool runs entirely on your local machine. No information leaves your computer, and no data gets sent to a server.

**Can I change the barcode size?**
The tool generates standard EAN-13 dimensions by default. You can adjust the scale settings in the print options menu before you save the file.

**What if my Excel file has errors?**
The software checks your file for valid EAN-13 numbers before it starts the generation process. If a number is invalid, the software displays a warning and shows you which row contains the error.

**Does this software require an internet connection?**

## 🔍 Troubleshooting
*   **Application won't open:** Ensure you have the latest Windows updates installed.
*   **Barcodes look blurry:** EPS files are vector files. If you view them in a basic image viewer, they may look pixelated. Import them into professional software like Adobe Illustrator or a print document to see the true resolution.
*   **Excel file not loading:** Make sure your file is closed in Excel before you try to import it into the barcode maker.
